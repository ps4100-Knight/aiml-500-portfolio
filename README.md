# AIML-500 Portfolio

A two-page, buildless static website for Pruthviraj Solanki's Machine Learning Fundamentals course portfolio. The site uses only HTML and CSS, so GitHub Pages can serve it directly.

## Files

- `index.html` — course portfolio home page
- `artifacts.html` — AI/ML Timeline presentation and reflection
- `styles.css` — shared responsive design

## Publish with GitHub Pages

1. Create a new **public** repository on GitHub. A repository name such as `aiml-500-portfolio` will produce a URL like `https://YOUR-USERNAME.github.io/aiml-500-portfolio/`.
2. Upload the three site files (`index.html`, `artifacts.html`, and `styles.css`) to the repository's top level. Keep the filenames unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the default branch (usually `main`) and the `/ (root)` folder, then save.
6. After GitHub finishes building the site, the Pages panel will show its public URL. Open that URL and check both the home page and the Artifacts link.

GitHub Pages hosting is free for a public repository. The slides are embedded from Google Slides; if the embed is restricted by the presentation's sharing settings, visitors can use the direct presentation link on the Artifacts page.

## Updating the portfolio

Edit the HTML files in GitHub or replace them with updated versions. Add new course work to `artifacts.html`, update the artifact count near the top of that page, and add a home-page preview if desired. Changes to the default branch are automatically published by GitHub Pages.
